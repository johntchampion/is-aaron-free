# Is Aaron Free?

A mobile-first React app that shows whether Aaron is free or working on any given day, based on his alternating two-week schedule.

## Features

- Today's status shown prominently on load
- Scrolling week-by-week view for the next year
- Date picker to check any specific date
- Light/dark mode via system preference

## Getting started

```bash
npm install
npm run dev
```

## Stack

React 19 · TypeScript · Vite
